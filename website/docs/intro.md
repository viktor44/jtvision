# JT Vision

JT Vision is a Java text-based user interface framework inspired by the classic Turbo Vision library. Build terminal applications with windows, dialogs, menus, status lines, and full keyboard/mouse input — cross-platform on Windows, macOS, and Linux.

## Features

- Multiple, resizeable, overlapping windows
- Pull-down menus
- Mouse support
- Dialog boxes
- Built-in color installation
- Buttons, scroll bars, input boxes, check boxes, and radio buttons
- Standard handling of keystrokes and mouse clicks


## Requirements

Java 8 or newer.
