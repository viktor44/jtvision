# Examples

Run scripts are in the `scripts/` folder of the repository — `.bat` for Windows, `.sh` for Unix/macOS.

| Script | Description |
| --- | --- |
| `run-hello` | Minimal starter: greeting dialog, basic menu, and status line. |
| `run-demo-demo` | Comprehensive showcase — puzzle, calendar, ASCII chart, calculator, file editor, color dialogs, mouse options, desktop state save/restore, and event viewer. |
| `run-demo-dir` | Collapsible directory tree viewer with filesystem navigation. |
| `run-demo-edit` | Multi-document text editor with cut/copy/paste, find/replace, file dialogs, and window management. |
| `run-demo-forms` | Phone directory database — form-based data entry with file I/O and new/edit/delete record operations. |
| `run-demo-palette` | Color palette customization demo showing per-view and per-window palette overrides. |
| `run-demo-mmenu` | Cycles through three different menu bar configurations at runtime. |
